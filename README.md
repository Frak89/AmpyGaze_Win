# AmpyGaze per Windows

Webcam locale: riproduce un MP3 quando lo sguardo si abbassa e ferma l'audio quando si rialza.

## Versione EXE

Apri Actions → Build AmpyGaze Windows EXE → ultima build riuscita → Artifacts → AmpyGaze-Windows-x64. Estrai tutto e avvia AmpyGaze.exe. Non serve installare Python. Carica un MP3, premi Avvia e calibra le due posizioni. Per avviare all'accesso Windows usa la casella nell'app; conserva la cartella in una posizione stabile.

L'elaborazione avviene sul PC, senza registrare o trasmettere immagini. La stima dello sguardo richiede luce e posizione adeguate. Webcam e audio vanno verificati sul PC reale.

Il sorgente usa Python 3.11 solo per lo sviluppo e la compilazione. La versione EXE include l'ambiente necessario.
